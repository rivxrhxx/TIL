# 웹 소켓(Web Socket)

웹 소켓이란 두 프로그램 간의 메세지 교환을 위한 통신 방법중 하나이다.

웹소켓은 서버와 클라이언트간에 연결을 유지하여 언제든 양방향 통신 또는 데이터 전송이 가능하게 하는 기술이다.

Real Time Web application 구현을 위해 널리 사용되어지고있다.

- 실시간 채팅, 주식 시세 업데이트 , 실시간 통지 및 알림에 사용된다.

### WebSocket을 사용하는 이유

실시간 채팅 앱과 같은 요구사항들을 반영하기 위해 클라이언트에서 매번 HTTP 프로토콜을 통해 서버에 요청하는 것은 비효율적이다.

클라이언트에서 Ajax통신을 통해 보완할수있지만. Ajax도 http를 사용하는것이기때문에 여전히 문제가 돼 웹소켓을 통해 이를 해결할수있다.

### WebSocket 사용 시 주의점

- WebSocket은 **stateful** 프로토콜로써 connection을 항상 유지해야하기 때문에 트래픽이 많은 경우 서버에 부담이 될 수 있다.
- 연결이 계속 유지되어야 하기 때문에, 연결이 끊어졌을 때 적절히 대응할 수 있어야 한다.
