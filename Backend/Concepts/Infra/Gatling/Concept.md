# Gatling
Gatling은 오픈 소스 기반의 고성능 부하 테스트 도구로, 주로 웹 애플리케이션의 성능 테스트에 사용된다. Scala와 Java를 지원하며 간단한 설정만으로도 부하 테스트를 수행할수있다.

**게틀링의 주요 특징**

1. 높은성능 : Gatling은 비동기적이고 Non-Blocking 방식으로 동작하여, 적은 자원으로도 높은 부하를 생성할 수 있다. 이를 통해 수천 수만명의 동시 접속자를 시뮬할수있다.
2. 사용자 친화적: Gatling은 테스트 시나리오를 DSL형식으로 작성할수있어 개발자들이 쉽게 이해하고 작성할수있다. 또한 테스트 결과를 시각화하여 제공해 성능 문제를 직관적으로 파악할수있다.
3. 확장성 : Gatling은 다양한 프로토콜을 지원하며 , 플러그인을 통해 기능을 확장할 수 있다. 이를 통해 HTTP뿐만 아니라 다양한 네트워크 프로토콜에 대해 부하 테스트를 수행할 수 있다.
4. 자동화 : CI/CD 파이프라인에 쉽게 통합할 수 있어, 지속적인 성능 모니터링 및 테스트 자동화가 가능하다.
