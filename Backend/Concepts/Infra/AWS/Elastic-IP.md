# **Elastic IP (탄력적 IP)**

EIP는 인터넷을 통해 접속할수있는 **고정적인 공인 IP를 주소를** 할당할 수 있고, 인스턴스에 연결할수있는 서비스

모든 인스턴스 또는 네트워크 인터페이스에 탄력적 IP 주소 연결이 가능함

그러므로 IP가 바뀌지않고 계속 사용하고 싶으면 탄력적아이피 사용하기

## 왜 사용하는데?

인스턴스 public ip는 고정된 ip주소가 아니라 **유동적인 IP주소임**

EC2 인스턴스를 중지하고 다시실행시키면 기존 할당받은 IP주소가 변경되버림

이를 해결하고자 **한번 할당 받으면 변하지않는** 탄력적 IP를 사용하는것이다.
