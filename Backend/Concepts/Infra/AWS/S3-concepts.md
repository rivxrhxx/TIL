# Amazon S3

Amazon Simple Storage Service의 약자로 데이터를 객체단위로 관리하는 오브젝트 스토리지 서비스

내가 하는 프로젝트에 프로필 사진을 등록하기위해 이미지나 동영상같은 파일들을 서버에 올려야할때가 많다

이럴때 S3를 사용해 스토리지에 보관해놓으면 쉼고 간단하게 파일들을 업로드하여 관리할 수 있다.

s3는 이외에도 웹 서버 역할을 수행하기도 하고 쿼리를 사용하여 집계 기능도 수행할 수 있다.


## S3용어

- 버킷: 객체를 저장하는공간
- 객체: 동영상이나 이미지같은파일
- 버킷명: 유일한이름
- 객체 키 : 객체 식별자 . 모든 객체 하나씩 가지고있음
