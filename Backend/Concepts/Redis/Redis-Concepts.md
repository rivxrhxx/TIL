Redis는 원격에 위치하고 프로세스로 존재하는 In-Memory 기반
Key - value 형식으로 저장되는 NoSql database이다.

✔️ **인메모리 ( In-Memory )**

- 컴퓨터의 주기억장치인 RAM에 데이터를 올려서 사용하는 방법
- RAM에 데이터를 저장하게 되면 메모리 내부에서 처리가 되므로  
    데이터를 저장/조회할 때 하드디스크를 오고가는 과정을 거치지 않아도 되어 
    **속도가 빠름**
    
## ⁉️DB가 있는데 Redis 를 왜 사용할까?

DB는 데이터를 **직접저장**하기 때문에 데이터가 손실되지않지만

매번 디스크에 접근해야하기 때문에 **사용자가 많아지면 부하가 많아져서** 느려질 수 있어서 캐시 서버를 도입해야함

이 캐시서버가 바로 **Redis!**

같은요청이 여러번 들어올때 Redis을 사용해서 매번 DB를 거치지 않고

캐시 서버에서 저장해놨던 값을 바로 가져와 **DB의 부하를 줄이고** **서비스의 속도도 느려지지 않게 할수있음**

## Redis의 특징

- 비정형 데이터를 저장, 관리하기 위한 오픈 소스 기반의 NoSQL

- 데이터를 메모리에 저장해 대기시간을 낮추고 처리량을 높힘
- Redis는 영속성을 보장하기위해 데이터를 디스크에 저장함 
- 
- 주 용도는 캐싱, 채팅,메세징  및 대기열 , 랭킹보드(순위표),인증토큰 저장,실시간분석
