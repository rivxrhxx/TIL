# 쿠키(Cookie)

- 서버가 클라이언트의 웹 브라우저에 저장하는 데이터
- 쿠키의 데이터는 key-value로 구성되어있다 Spring타입임
- 브라우저마다 저장되는 쿠키는 다르다. 즉 , 서버에서 브라우저가 다르면 다른 사용자로 인식함
- 사용자가 서버쪽으로 요청할때 쿠키의 정보를 함께 보내서 서버가 사용자를 식별할수있게함

### 쿠키 생성 과정

1. 클라이언트와 서버가 한번도 통신한 이력이없으면 존재하지않음. 쿠키가 없는 상태에서 서버에서 요청을 보내면 서버에서는 쿠키를 생성하여 response함
2. 다음은 클라이언트에서 쿠키정보 저장하고 , 추후 보내는 request에는 쿠키를 담아 보내서 서버에서 쿠키를 통해 클라이언트 상태를 파악하는 것이다.

### 쿠키 사용목적

1. 세션관리
2. 개인화
3. 트래킹

### 쿠키의 사용되는 예시

- ID 저장, 로그인 상태 유지
- 일주일간 다시 보지 않기.
- **최근 검색한 상품들을 광고에서 추천**
- 쇼핑몰 장바구니 기능

#### 쿠키의 단점

- 방문했던 웹 사이트에 대한 정보 및 개인정보가 기록되기에 사생활 침해의 소지가 있다.
- 보안에 취약함(직접 사용자가 임의로 고치거나 지우거나 제3자가 가로채기 쉬움)
