# 💁 ORM(Object-Relational Mapping)

**ORM은 애플리케이션의 Class와 RDB(Relational DataBase)의 테이블을 매핑해주는 기술이다.**

이를 통해 애플리케이션과 데이터베이스를 연결할 때 SQL을 직접 작성하지 않아도 되고,

개발자는 **애플리케이션 개발 언어(예: Java)만으로 데이터베이스에 접근하고 조작할 수 있다.**

### ✌️ 예시

SQL

```sql
SELECT * FROM user WHERE id = 1;
```

**하지만 ORM이있다면**

```java
User user = userRepository.findById(1L).get();
```

**ORM이 내부에서 SQL을 자동으로 만들어서 실행해줌**

## 👀장점 / 단점

### **장점**

- **SQL문이 아닌 Method 를 통해 DB를 조작할수있어 , 개발자는 객체 모델을 이용해 비즈니스 로직을 구성하는데에만 집중이 가능하다**
- **객체 지향적인 코드 작성이 가능하다 . 오직 객체지향적 접근만 고려하면 되기때문에 생산성 증가**

## 단점

- **성능 문제 : 대량의 데이터를 처리하는 경우에는 성능에 문제가 발생할수도있다**
- **ORM은 모든 데이터베이스 기능을 완벽하게 지원하는것이 아니기에 일부 고급 데이터베이스나 복잡한 쿼리는 직접 SQL로 관리해야 할수도있다.**
