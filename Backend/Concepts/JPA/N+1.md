# N+1 문제 무엇인지 알려줘

### 우선 정의부터 설명해줄게

> 연관관계가 있는 엔티티를 조회할 떄 조회된 개수 N개 만큼의 쿼리가 추가로 발생하는것.

### 그러면 발생하는 원인이 뭘까?

RDB와 객체지향 언어 간의 페러다임 차이로인해 발생함. 객체는 연관관계를 통해 레퍼런스를 가지고있으면 언제나 메모리내 Radom Access를 통해 연관 객체에 접근할 수 있지만 RDB경우 Select 쿼리를 통해 조회할수 있기 때문이다.

### 그냥 방치 하면 안댐?

N+1 문제가 발생하면 쿼리가 배수적으로 증가해 **DB에 큰 부담이 발생한다.**
