# JPA(Java Persistence API)

**JPA는 자바에서 ORM 기술을 사용해 객체를 데이터베이스에 저장하고 관리할 수 있도록 표준 인터페이스와 기능을 제공하는 API이다.**

JPA를 사용하면 객체와 관계형 데이터베이스 간의 매핑을 손쉽게 처리할수있다

데이터베이스의 CRUD 작업을 간편하게 수행할수있다.

## 객체 매핑

| 어노테이션       | 설명                                                      |
| ----------- | ------------------------------------------------------- |
| @Entity     | 테이블과 매핑한다고 JPA에게 알려줌, @Entity가 사용된 클래스를 엔티티 클래스라고 함     |
| @Table      | 엔티티 클래스에 매핑할 테이블 정보를 알려줌 ex) @Table(name=”MEMBER”)      |
| @Id         | 엔티티 클래스의 필드를 테이블의 기본 키에 매핑함, 이렇게 @Id가 사용된 필드를 식별자 필드라 함 |
| @Column     | 필드를 컬럼에 매핑함 ex) @Column(name=”AGE”                      |
| 매핑 어노테이션 없음 | 매핑 어노테이션이 없다면 DB에 이름이 같은 컬럼으로 매핑됨                       |
