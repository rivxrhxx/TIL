# **객체지향(Object Oriented Programming)**

객체지향은 실제세계를 모델링해 소프트웨어 개발을하는 방법

객체지향의 3가지 특징으로는 **캡슐화,상속,다형성이있다**
[[SOLID-concepts]]
## 1. 캡슐화

캡슐화란 관련된 데이터와 알고리즘(코드)이 하나의 묶음으로 정리된것으로써 개발자가 만들었으며

관련된 코드와 데이터가 묶여있어 오류가없어 사용하기편하다.

데이터를 감추고 외부 세계와의 상호작용은 메소드를 통한 방법인데, 라이브러리로 만들어 업그레이드하면 쉽게 바꿀수있다.

**캡슐화는 변수를 직접 만지지 못하게 하고, 메서드를 통해 안전하게 사용하게 하는 것이다.
## 2. 상속

상속은 이미 작성된 클래스를 이어받아서 새로운 클래스를 생성하는 기법이다 기존의 코드를 
재활용함을 의미함

객체지향 방법중 큰 장점

```java
class Animal {
	String name;
    void eat() {
        System.out.println("동물이 먹고 있습니다.");
    }
}

```

```java
class Dog extends Animal { //Animal을 상속받음
    void bark() {
        System.out.println("강아지가 짖습니다: 멍멍!");
    }
}
```

```java
public class Main {
    public static void main(String[] args) {
        Dog dog = new Dog();

        dog.eat();   // 부모 클래스 Animal의 기능 사용
        dog.bark();  // Dog 자신만의 기능 사용
    }
}
```

## 3. 다형성

하나의 이름(방법)으로 많은 상황에 대처하는 기법. 개념적으로 동일한 작업을 하는 함수들에 똑같은 이름을 부여할수있으므로 코드가 더간단해짐.



# 3가지특성에 대한 장점

- 신뢰성 있는 소프트웨어를 쉽게 작성할 수 있다. (개발자가 만든 데이터를 사용하기에 신뢰할 수 있다.)
- 코드를 재사용하기 쉽다.
- 업그레이드가 쉽다.
- 디버깅이 쉽다.

# 객체지향의 장단점

## 장점

- 코드의 재활용성이 높음
- 코딩이 절차지향보다 간편함
- 디버깅이 쉬움

## 단점

- 처리속도가 절차지향보다 느림
- 설계에 많은 시간소요가 들어감
