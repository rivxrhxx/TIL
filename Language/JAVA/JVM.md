# JVM(자바 가상 머신)

자바를 실행시키기위한 가상기계

자바 언어에서만 사용하는것이 아닌 코틀린 스칼라 언어에서도 JVM 동작방식이 사용된다.

따라서 JVM을 정확히 이해하면 자바에서 파생된 모던 언어를 이해하는데 있어 수월해지며 내부에서 정확히 어떻게 동작을 해서 코드가 실행이 되는지 개념을 알면 코드 최적화 리펙토링에 매우 도움이된다.

## 자바 가상 머신(JVM) 에 동작방식

1. 자바 프로그램을 실행하며 JVM은 OS로부터 메모리를 할당받는다.
2. 자바 컴파일러(javac)가 자바 소스코드 (.java)를 바이트코드로 컴파일 한다.
3. Class Loader는 동적 로딩을 통해 필요한 클래스들을 로딩 및 링크 하여 실질적인 메모리를 할당 받아 관리하는 영역)에 올린다.
